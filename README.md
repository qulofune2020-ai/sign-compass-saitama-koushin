# Sign Compass 埼玉・更新版

埼玉県の63市町村で、看板の許可を**更新**するときに確かめることを出す道具。看板業者向け。
市町村と看板の仕様（種類・面積・高さ）、更新に合わせてすること（板面替え・表示者の変更）を選ぶと、
更新に効く9つの観点（窓口・適用条例・許可期間と更新・点検報告・管理者・手数料・変更届・板面替え・旧基準の看板）を
「要確認・注意・問題なさそう」の3段階で、出典（資料名・ページ・取得日・短い引用）と「窓口に電話で聞くこと」つきで出す。

判定は目安で、許可の要否や違法かどうかは決めない。申請書類の作成はクロフネ行政書士事務所へ。

- 収録：埼玉県の63市町村すべて。窓口は県の「屋外広告物許可事務担当窓口」（令和8年4月1日現在）から。独自条例の10市（さいたま・川越・川口・越谷・熊谷・春日部・戸田・三郷・八潮・新座）は市の資料の記録。上尾市（3週間前）・蕨市・狭山市（10日前）は市の案内の更新期限を重ねている
- 戸田市・新座市の例規集（条例・施行規則）は自動では取れなかった（403）。手で保存したら条例・規則の記録を足す
- もとは [Sign Compass 東京版](https://github.com/qulofune2020-ai/sign-compass-tokyo) の画面、[Sign Compass（更新版）](https://github.com/qulofune2020-ai/sign-compass-sanyo-koubo) の埼玉県・さいたま市の記録、[Sign Compass（埼玉）](https://github.com/qulofune2020-ai/kanban-yomidokoro-saitama) の独自条例9市の記録（2026-11-23 に資料を取り直して照合）
- 仕組みは [Sign Compass（埼玉）](https://github.com/qulofune2020-ai/kanban-yomidokoro-saitama) と同じ。引用が原文にあるかは Claude ではなくプログラムが文字で照合する
- 条例・手引きの本文はリポジトリに置かない（URL・取得日・sha256・100字以内の引用だけ）。資料の本体は `資料/`（gitignore）
- 依頼者・施主・案件（件数・満了月など）の情報は扱わない

## 使い方
- `npm run 取得 -- <id>` 資料を取る ／ `npm run 照合 -- <自治体>` 引用を原文と照らす ／ `npm run 判定` 典型ケース
- `npm run build` 静的書き出し ／ `npm run 確認` 公開前の確認（照合・判定・漏れ・リンク）
